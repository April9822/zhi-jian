# 知间设计系统守护规则

> 此规则自动加载。任何CSS/组件/页面的视觉产出必须遵守。
> 修改 DESIGN-COLOR-SYSTEM.md 中的色值需要系统架构师批准。

---

## 一、色彩路线（不可偏离）

知间的色彩叙事：「从夜晚到黎明 From Night To Sunrise」

```
冲突进入  Night     #101827 深夜蓝
   ↓
倾诉     Mist      #8EA5B5 雾蓝
   ↓
理解     Morning   #DCE5DE 晨雾绿
   ↓
分析     Paper     #F3EFE7 暖米色
   ↓
成长     Sunrise   #F3E3C1 晨曦金
```

## 三、禁止使用的色彩

以下色彩在知间任何页面中**绝对禁止**：

| 禁止 | 原因 |
|------|------|
| `#FFFFFF` 纯白背景 | 太刺眼、太冷、缺乏温度 |
| `#000000` 纯黑字体 | 对比度过高、不柔和 |
| 蓝紫科技渐变 | 机器人感、违反智者调性 |
| 荧光色（任何） | 刺眼、廉价感 |
| 红色（`#FF0000` / `#E53E3E` 等） | 警告/错误暗示，违反不评判原则 |
| 法庭黑白灰配色 | 判官隐喻、冰冷 |
| 高饱和渐变 | 花哨、不专业 |

## 四、字体规范

- 系统字体栈：`"PingFang SC", "Microsoft YaHei", "Hiragino Sans GB", "Noto Sans SC", sans-serif`
- 不使用外网字体（Google Fonts / Adobe Fonts 等）
- 不加载字体文件（保持 HTML 自包含）
- 字重范围：300(细) / 400(常规) / 500(中等) / 600(半粗)
  - 禁止使用 700+ 粗体（太强势）

## 五、间距系统

使用 4px 基准网格：
```
间距阶梯：4 / 8 / 12 / 16 / 20 / 24 / 32 / 40 / 48 / 64 / 80
```

## 六、圆角规范

| 元素类型 | 圆角 |
|------|------|
| 按钮 | 12px |
| 卡片 | 16px |
| 输入框 | 12px |
| 标签/徽章 | 8px |
| 圆形图标 | 50% |

## 七、动效规范

| 属性 | 值 |
|------|------|
| 默认缓动 | `cubic-bezier(0.4, 0, 0.2, 1)` （Material Design 标准缓动） |
| 微交互时长 | 150ms - 250ms |
| 页面转场时长 | 400ms - 600ms |
| 呼吸动画时长 | 3s - 4s（慢呼吸） |
| 颜色过渡 | 800ms - 1200ms（色彩情绪渐变） |

## 八、移动端底线

- 触控目标 ≥ 44px × 44px
- 正文字体 ≥ 16px
- 输入框字体 ≥ 16px（防 iOS 自动缩放）
- 必须适配 `safe-area-inset-*`
- 必须设置 `-webkit-text-size-adjust: 100%`
- 320px 宽度不出现水平滚动条

## 九、自包含要求

所有 HTML 文件必须是**完全自包含**的单文件：
- ❌ 不引用外部 CDN
- ❌ 不引用外部字体
- ❌ 不引用外部图片（SVG内联 / CSS绘制）
- ❌ 不引用外部 CSS 文件（全部内联或 `<style>`）
- ❌ 不引用外部 JS 文件
- ✅ 图表使用纯CSS实现
- ✅ 图标使用内联SVG或CSS绘制

## 十、检查清单

每次视觉产出必须对照检查：
- [ ] 是否按页面类型使用了正确的背景色？
- [ ] 是否出现了禁止色彩清单中的任何颜色？
- [ ] 字体是否来自系统字体栈？
- [ ] 触控目标是否 ≥ 44px？
- [ ] 图表是否纯CSS实现（无JS绘图库）？
- [ ] HTML是否完全自包含？
- [ ] 是否使用了知间核心术语（关系养分/情境回顾/成长建议等）？
