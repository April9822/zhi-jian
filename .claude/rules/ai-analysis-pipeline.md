# 知间AI分析管线规范

> 此规则自动加载。所有AI分析功能的开发必须遵守此流程。
> 强制要求：先建模，后分析。禁止跳过任何步骤直接输出结论。

---

## 一、核心原则

**先还原真实关系场景，再解读问题。不是机械解读文本。**

## 二、强制分析流程（6步，不可跳过）

```
步骤1: 角色识别
步骤2: 关系推断建模
步骤3: 搭建对话时间线
步骤4: 生成双方情绪曲线
步骤5: 输出分层分析报告（个人层 + 关系层）
步骤6: 生成可落地的成长建议
```

每一步的输出是下一步的输入。**禁止用一个Prompt一次性生成所有内容。**

## 三、各步骤详细规范

### 步骤1：角色识别
- 从对话中识别双方身份
- 区分说话者（A和B）
- 推断角色关系（情侣/家人/同事/朋友等）及其依据
- **禁止**：使用刻板印象推测角色
- **格式**：输出角色标注后的对话

### 步骤2：关系推断建模
- 基于对话内容推断双方关系模型
- 包括：亲密度、权力结构、沟通频率、关系历史推测
- **禁止**：做人格诊断、给关系"好坏"评价
- **格式**：输出关系模型描述（非评分）

### 步骤3：对话时间线搭建
- 按时间顺序还原对话
- 标注关键节点：起因 → 转折点 → 情绪爆发点 → 沟通失效点 → 冷战/缓和
- 使用Gottman四骑士框架作为标注参考（批评/蔑视/防御/筑墙）
- **禁止**：将四骑士作为人格标签
- **格式**：输出时间线 + 节点标注

### 步骤4：情绪曲线生成
- 逐句情绪标注
- 生成双方情绪强度变化曲线数据
- 标注情绪转折节点及其触发事件
- **禁止**：只用"正面/负面"二分（情绪是丰富的）
- **格式**：输出情绪数据（供前端纯CSS渲染曲线）

### 步骤5：分层分析报告
分为两层：

**个人层（6模块）**：
- 个人状态（心态/情绪基调/沟通状态——温和叙述，不做诊断）
- 情绪变化（全程起伏/波动节点）
- 表达风格（沟通习惯/语言特质/表达盲区——描述行为，不定性）
- 情绪触发点（关键诱因——帮用户看见自己的"按钮"）
- 关系高光时刻（温柔/包容/共情瞬间——正向设计）
- 修复/成长建议（专属可落地方案）

**关系层（5维度+情境回顾）**：
- 理解度 / 倾听度 / 冲突值 / 修复度 / 信任度
- 情境回顾：剧本式叙事 → 转折点 → 未被说出的需求 → 关系养分变化

**禁止**：
- 给维度打分（不出现"理解度75%""信任度3/5"）
- 使用"关系能量"术语 → 使用"关系养分"

### 步骤6：成长建议生成
- 基于分析结果生成可操作的沟通方案
- 必须具体："下次可以说……"而非"建议改善沟通"
- 必须指向直接沟通："去跟TA聊聊"
- **禁止**："好好沟通""多理解对方"等空洞建议
- **禁止**："你永远""你从来不"等绝对化措辞
- **禁止**：建议分手/离婚/辞职等极端行为

## 四、Prompt 工程设计准则

### System Prompt 必须包含
1. 角色设定（智者/关系教练，非判官/医生）
2. 知间宪法三大禁止 + 三大聚焦
3. 本步骤的具体任务和输出格式
4. 禁止词汇库（完整列表见 AI 工程师智能体定义）

### Few-shot 要求
- 每个步骤的 Prompt 至少包含 2 个 Few-shot 示例
- 示例必须是中文对话
- 示例必须展示"正确的输出格式"（无评判、无标签、温暖但不鸡汤）

### 平衡检查
- 每个分析步骤末尾追加："在你的分析中，是否有一方被更严厉地评判？如果是，请平衡。"
- 如果只有单方输入，必须在分析中为缺席方构建"最佳解释"

## 五、禁止词汇库（Prompt中硬编码）

以下词汇在 AI 输出的任何位置都禁止出现：
```
回避型人格 / 焦虑型依恋 / NPD / BPD / 边缘型 / 自恋型 /
讨好型 / 控制型 / 依赖型 / 反社会人格 /
躁郁 / 抑郁症 / 焦虑症 / 人格障碍 /
你错了 / 责任占比 / 是你的问题 / 责任在你 /
你太敏感 / 你反应过度 / 你小题大做 /
分手 / 离婚 / 辞职 / 断绝关系 /
这人不行 / 他不配 / 离开他 / 关系没救了 /
看心理医生 / 需要治疗 / 心理疾病 /
永远 / 从来不 / 完全不 / 一点都不 /
```

## 六、输出质量检查清单

每次AI分析输出后必须对照检查：
- [ ] 是否出现禁止词汇？
- [ ] 是否对缺席方做了确定性的动机推断？
- [ ] 是否在建议中指向了直接沟通（而非替代沟通）？
- [ ] 是否使用了温暖、非学术化的语言？
- [ ] 是否标注了"AI不能替代专业帮助"的边界说明？
- [ ] 个人层6模块是否完整？
- [ ] 关系层5维度是否都有具体对话证据支撑？
- [ ] 情境回顾是否以剧本式叙事呈现？
- [ ] 是否使用了"关系养分"（而非"关系能量"）？
