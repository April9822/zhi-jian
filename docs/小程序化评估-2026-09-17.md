## 二、小程序视角的四个决定性发现

### 🔴 1. 资源体积是致命硬伤（主包 2M / 总包 20M）

实测 `public/` 目录 **99M**，`dist/` 构建产物同样 **99M**（vite 将 public 原样复制）。

| 文件 | 体积 | 性质 |
|---|---|---|
| `所有参考.pdf` | **52M** | 设计参考稿，误入 public |
| `心仪.pdf` | 7.6M | 设计参考稿，误入 public |
| `2.png` | 6.5M | 疑似设计原图 |
| `3.png` | 5.4M | 疑似设计原图 |
| `1.png` | 4.7M | 疑似设计原图 |
| `参考.pdf` | 2.9M | 设计参考稿 |
| 其余 20 张 PNG | 合计 ~17M | 图标多为 500KB–1.3MB/张 |

**结论**：光静态资源就 99M，是微信小程序主包上限（2M）的约 **50 倍**、总包上限（20M）的约 **5 倍**。当前形态**完全不可能**直接搬成小程序。资源必须彻底清洗：52M 参考 PDF 移出项目、PNG 压成 WebP/走 CDN、图标改用 iconfont 或 SVG 组件。

### 🔴 2. 渲染层三重 Web API 依赖，需 100% 重写

`src/modules/garden.js` 的核心视觉同时用了三种小程序不支持的渲染手段：

- **SVG**：`document.createElementNS('...svg')` 动态生成 `<path>` 画关系花园根脉
- **Canvas 2D**：`getContext('2d')` + `createRadialGradient` + `requestAnimationFrame` 画光晕粒子动画
- **DOM 操作**：`document.createElement('span')` / `document.body.appendChild` 拼接胶囊、浮层

小程序是**双线程架构（逻辑层 JS + 渲染层 WXML），逻辑层禁止操作 DOM**。这三条链路在小程序里要分别改写成：
- SVG → 小程序 canvas 2d 绘制，或 Skyline 渲染引擎的能力
- Canvas → `wx.createSelectorQuery().select('#canvas').fields({node:true})` 拿节点 + canvas 2d 同层渲染，`requestAnimationFrame` 换 `canvas.requestAnimationFrame`
- DOM → `setData` 驱动 WXML 数据绑定

### 🟠 3. 存储与网络层需换 wx 封装

- **存储**：`src/core/state.js` 用 `localStorage`（同步）→ 需换 `wx.setStorageSync` / `wx.getStorageSync`，且受单 key 1M / 总 10M 限制。
- **网络**：`src/modules/input.js` 用 `fetch('/api/analyze')` → 需换 `wx.request`，强制 HTTPS + **域名白名单**（Vercel 域名需在小程序后台登记）。

### 🟢 4. 架构上有一处先天优势

`api/analyze.js`（Vercel Serverless 调 DeepSeek）是**服务端调用**，API Key 不暴露前端。这个分层恰好适配小程序——小程序只需 `wx.request` 白名单 Vercel 域名即可，**无需在小程序端直接调 DeepSeek**。逻辑层（判定链、数据模型、AI 结果解析）是纯 JS 无 DOM，可复用 60–70%。

## 三、可行性结论

**「Web 版上线」和「小程序版上线」是两个完全不同的工程量级：**

| 维度 | Web 版上线 | 小程序版上线 |
|---|---|---|
| 视图层 | 零改动 | **100% 重写**（SVG/Canvas/DOM → WXML/canvas 2d） |
| 逻辑层 | 零改动 | 可复用 60–70% |
| 资源 | 需清洗 99M | 需彻底清洗 + 压到 <20M |
| 存储/网络 | 零改动 | 换 wx 封装 |
| 审核合规 | 轻 | **重**（情感敏感 + AIGC 双敏感） |

**判断**：如果目标是"上线给真实用户用"，Web 版是 1–2 天的收口；小程序版是一次**重写视图层 + 洗资源 + 走微信审核（周期通常数周）**的中型重构。二者不冲突——Web 版可先上线验证产品，小程序版作为第二个分发渠道再推进。

---

## 四、如果确定做小程序，路径（5 步）

1. **资源清洗**（先做）：52M 参考 PDF 移出；23 张 PNG 转 WebP 压到 <500KB/张或走 CDN；图标改 iconfont。
2. **逻辑层复用**：`src/core/` 判定链 + `src/services/` 数据模型 + `api/` 服务端原样保留，抽成小程序可引用的纯 JS 模块。
3. **视图层重写**：按页面拆分（首页/录入/花园/报告/我的），花园用 canvas 2d 同层渲染重写 SVG 根脉与粒子动画。
4. **wx 封装层**：`utils/request.js`（封装 wx.request + token）、`utils/storage.js`（封装 wx storage）。
5. **合规 + 审核**：隐私政策、用户授权（采集的是真实私人对话内容）、AIGC 生成式 AI 服务备案、微信审核材料。
