# 知间 V2 · 人工验收清单（L4 · 只能人眼看的部分）

> 用途：机器能测的（逻辑 / DOM 契约 / 真实浏览器行为）已由
> `tests/e2e-dom-contract.test.js`（L2，24 条）与 `scripts/check-e2e.mjs`（L3，真实浏览器 15 条）覆盖。
> 本清单只列**机器判不了**的部分 —— 美学、调性、中文渲染、真机体感。
> 请在**真机（建议 iPhone 窄屏 + 桌面宽屏各一次）**按此逐项看，每项给出「过 / 不过 + 描述」。

## 一、美学与调性（为什么机器测不了：无 ground truth，属主观判断）

| # | 检查项 | 怎么看 | 判据 | 结论 |
|:--:|---|---|---|---|
| A1 | **暖金是否「不荧光」** | 看根脉（`root-main`）、选中动物的光点、选中态发光 | 应是**低透明度暖金**（`#D5A85A` 系，rgba<0.4）；**不得有荧光感/刺眼**（§A.6.4 纪律） | |
| A2 | **「空境美学」是否成立** | 全新用户（清 localStorage）打开花园 | 应**克制、留白、安静**；不显空荡冷清，不显拥挤热闹（PRD §10.8） | |
| A3 | **五区域是否有「纵深层次感」** | 看古树（中景）/ 花丛·溪谷·苗圃·营地（近景）/ 远山（远景） | 应有前中后景层次，**不是平铺**；远山是水墨剪影感 | |
| A4 | **区域标签（`.glabel`）对比度是否够读** | 看「家人 · 古树」「爱人 · 花」「自我 · 新芽」等 | 应**清晰可读**，不被背景吞掉（早期截图里对比度偏低，重点看这个） | |
| A5 | **动物是否「可爱不土」** | 看狐狸/兔子/松鼠/小鹿 | 应与水墨暖调**协调**，不卡通突兀、不惊悚 | |
| A6 | **选中态是否「说清楚了」** | 点一只动物 | 应一眼看出「选中的是它」（暖金三段式：底 + 外发光 + 光点），**不是只变个色** | |
| A7 | **根脉是否「像生长的根」而非「连根线」** | 给某节点养分到不同档位（10/50/90） | thin 细弱、mid 有分叉、thick/full 更丰富；**是「变丰富」不是「变粗大」**（P0-3） | |
| A8 | **形态三态是否可辨** | 同一区域档位 10 vs 50 vs 90 | 应看得出「长大了/开花了」，不是等比放大 | |

## 二、动态与情绪体验（为什么机器测不了：一次性情绪体验，时长/帧断言抓不到）

| # | 检查项 | 怎么看 | 判据 | 结论 |
|:--:|---|---|---|---|
| B1 | **首次生长动效的「惊喜感」** | 清 `zhijian-garden-first-growth` 后首次进入花园 | 应有一场**克制但打动人**的生长；不卡顿、不突兀；且**只播一次**（幂等） | |
| B2 | **浇灌反馈（水珠 + 闪亮）** | 点生物 / 选动物 | 水珠应从元素上方自然落下；**不遮挡文字**、不残留 | |
| B3 | **Canvas 光斑的「呼吸感」** | 静观花园 10 秒 | 光斑缓动、不抢戏、不闪烁；与水墨调性一致 | |
| B4 | **切屏是否顺滑** | 花园 ↔ 倾诉 ↔ 报告 | 无黑屏闪、无跳变；`body` 背景过渡自然 | |
| B5 | **加载页 4 句文案的节奏** | 走一次分析（或看 loading 页） | 逐句浮现-停留-消失的节奏**不焦躁**；8 秒后变暖是「快好了」的暗示 | |

## 三、中文渲染 / 真机体感（为什么机器测不了：依赖字体/OS/IME/真机）

| # | 检查项 | 怎么看 | 判据 | 结论 |
|:--:|---|---|---|---|
| C1 | **中文字体与断行** | 真机看报告页长句、花园标签 | 无孤字、无异常断行、无方框（缺字） | |
| C2 | **窄屏软键盘顶起布局** | 320px 真机，点输入框弹键盘 | 布局**不塌**、输入框**不被键盘遮死**、可滚动到分析按钮 | |
| C3 | **320px 下动物仍可点** | 320px 真机点 4 只动物 | 全部可点、命中区不互相误触（机器已验 `offsetParent!==null`，人眼再验「好不好点」） | |
| C4 | **320px 无横向滚动** | 320px 真机横滑 | 不能左右滑出白边（机器已验 `scrollWidth≤320`，人眼复核观感） | |
| C5 | **深色/浅色环境观感** | 白天/夜晚各看一次 | 暖调在两种环境下都成立 | |
| C6 | **`prefers-reduced-motion` 降级体验** | 系统开「减弱动态效果」 | 动画应显著减弱/停止，但**功能不失效**（动物仍可点、报告仍可读） | |

## 四、内容与共情（为什么机器测不了：LLM 非确定性 + 属产品/伦理判断）

| # | 检查项 | 怎么看 | 判据 | 结论 |
|:--:|---|---|---|---|
| D1 | **分析洞察是否「到位」** | 用 3~5 段真实对话各跑一次 | 洞察**切中真问题**、不空洞；语气**共情不评判** | |
| D2 | **是否守住宪法「三禁」** | 重点看报告页 | 无人格诊断 / 无道德审判（你错了）/ 无侮辱标签 | |
| D3 | **「如果重来」的建议是否具体可用** | 看 what-if 区 | 应给出**具体可说的话**，不是泛泛而谈 | |
| D4 | **动物/区域命名是否统一（爱人 vs 伴侣）** | 全站扫一眼 | 面向用户统一用「**爱人**」（`check-constitution.mjs` 已静态锁定，人眼复核无漏网） | |
| D5 | **分享链接在微信打开是否正常** | 把分享链接发到微信点开 | 「TA 的那一半」正常渲染、滚动正常、CTA 可用 | |

## 五、人工验收「怎么记录」

每项填：`过 / 不过`，不过的写**现象 + 截图 + 复现步骤**。汇总后：
- 属**美学调性** → 交 UX / 产品设计师定夺
- 属**功能失效**（如动物点不动、报告渲染错） → 开 bug 单交工程师（附复现）
- 属**文案/宪法** → 交工程师（附应改为的文案）

> 建议截图命名：`qa-screenshots/<日期>-<屏幕>-<宽>px.png`（项目已有 `qa-screenshots/` 先例）。
